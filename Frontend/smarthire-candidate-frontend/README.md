# SmartHire Candidate Portal
React/Vite candidate frontend based on the supplied Candidate Portal prompt.
No signup/registration. Candidate login → dashboard → resume/profile → jobs → apply → applications → screening → proctored exam handoff → result → final status.
Run: `npm install` then `npm run dev`.
API base URL is in `.env.example`. Candidate-safe data only is rendered. No FCM registration, fake IDs, answer keys, internal AI screening data, interviewer data, or internal thresholds.
